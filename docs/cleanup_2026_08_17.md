## 1. Executive Summary

A structured, non-destructive reorganization was executed across the codebase to:
1. Preserve all core runtime modules and entry runners at the project root.
2. Centralize all unit tests in `tests/` and experimental/manual tests in `tests/manual/`.
3. Move one-off Python utilities to `scripts/one_off/` with automatic root-import bootstrap headers.
4. Quarantine ad-hoc and config-modifying scripts (`buy_amzn.bat`, `run_buy_check.bat`) in `scripts/dangerous/`.
5. Archive obsolete backups, logs, temp folders, and old model folders in `archive_cleanup_2026_08_17/`.
